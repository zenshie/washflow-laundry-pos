# WashFlow Laundry POS Demo
Open `index.html` in a browser or deploy the folder using GitHub Pages.
## Included
- Dashboard and order activity overview
- Laundry order entry with service, weight, add-ons and partial payment
- Order workflow: Received → Washing → Drying → Folding → Ready for pickup → Completed
- Record additional payments and outstanding balances
- Customer directory, sample service pricing and CSV export
- Browser localStorage persistence
## Demo limitations
This is a front-end demonstration. Data stays in the current browser and is not shared across devices. It has no authentication, cloud database, automated SMS, printer integration, accounting integration or real payment processing. Sample rates and records are fictional. Do not enter real customer data or rely on it for actual business accounting.
